# 脱敏说明

## 可以公开

- 评测流程、指标公式和数据字段设计；
- 不包含真实地址的通用脚本；
- 人工构造的示例 CSV；
- 不对应真实运行的示例报告；
- 经过审查的方法论、数据质量问题类型和优化思路；
- 开源模型、论文和公开数据集的正规引用。

## 不可公开

- 公司名称、客户信息和业务数据；
- 接口域名、IP、端口、请求头、账号、密码、token、cookie；
- 服务器型号、目录、日志、内部模型权重路径和部署拓扑；
- 原始人工文本、生成文本、问题池和完整数据集；
- 逐条真实预测、置信度、耗时和错误响应；
- 可反向定位内部系统的版本名、文件路径和截图；
- 未经审批的真实聚合指标或内部报告。

## 发布前检查

1. 全文搜索 URL、IP、邮箱、账号、token、secret、password 等模式；
2. 检查 CSV、JSON、日志和截图是否含真实文本；
3. 检查 Git 历史是否曾提交敏感文件；
4. 检查示例数值是否明确标注为合成；
5. 检查文档是否暗示公司采用了某个具体内部配置；
6. 由项目负责人或有权限人员完成最终审批。
