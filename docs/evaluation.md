# 评测流程

## 1. 冻结口径

先固定正类定义、标签映射、文本规范化方式、最大输入长度、截断方式和成功响应条件。每次运行记录匿名版本代号，不记录真实服务地址。

## 2. 数据质检

分别检查整段混合集、分句压力集、跨生成器压力集和训练候选集。重点排查空标签、重复问题、重复回答、跨分区泄漏、缺失结果和异常截断。

## 3. 小样本联调

先用合成或获准的小样本验证字段映射、结果数量、标签方向和异常处理。联调数据不计入正式指标。

### 3.1 公开脚本执行顺序

先执行结果文件校验：

```powershell
python src/validate.py data/demo_mixed.csv --result-file
```

校验通过后计算基础指标：

```powershell
python src/evaluate.py data/demo_mixed.csv
```

按需启用增强分析：

```powershell
python src/evaluate.py data/demo_mixed.csv `
  --group-by-length `
  --confidence-buckets `
  --output reports/demo_analysis.json
```

最后比较两个检测运行：

```powershell
python src/compare.py `
  data/demo_mixed.csv `
  data/demo_run_b.csv
```

脚本退出码约定：

- `0`：执行成功，或校验结果有效；
- `2`：参数、文件、编码、CSV 结构或数据内容无效。

## 4. 冻结测试

正式运行前冻结输入文件及其哈希。不同模型、推理实现或版本必须使用相同输入顺序、相同截断规则和相同标签映射。

## 5. 分层统计

- 正负混合集：Accuracy、AI 检出率、人工误检率、Precision、F1；
- 分句集：单独计算上述指标，并按原文 `id` 检查相关性；
- 纯 AI 跨生成器集：仅统计检出率和漏检；
- 分来源/主题/长度/截断状态报告样本数和指标；
- 小样本分组必须展示分母。

### 5.1 当前已实现的分层统计

当前公开脚本支持：

- 整体二分类指标；
- 按 `source` 分组；
- 可选的文本长度分组；
- 可选的 `generator` 分组；
- 可选的置信度分桶；
- 可选的阈值-指标曲线。

以下维度仍属于建议扩展，当前尚未内置：

- 按 `truncated` 分组；
- 按运行版本或推理后端分组；
- ROC-AUC、PR-AUC、ECE；
- 置信区间和显著性检验。

## 6. 一致性比较

对两个运行按 `id` 对齐，检查：

- 标签一致率；
- A 判 AI、B 判人工的数量；
- A 判人工、B 判 AI 的数量；
- 真实标签和来源字段是否一致；
- 若分数语义一致，再比较分数差异。

## 7. Bad Case

错误样本台账只保留匿名编号、真实/预测标签、长度桶、主题类别、截断状态、版本代号和错误类型。公开版不得包含原文。

## 8. 优化验证

阈值、规则、后处理和微调只能使用训练集、开发集或验证集。冻结测试集不得反复用于选方案。优化报告同时展示收益和代价，例如误检率下降是否伴随检出率明显下降。

### 8.1 阈值选择限制

阈值只能在开发集或验证集上选择。冻结测试集可以使用已经确定的阈值生成最终报告，但不能反复用于搜索最优阈值。

运行阈值曲线前必须确认：

1. 分数方向明确；
2. 分数跨样本可比较；
3. 分数不是“当前预测标签自身的置信度”；
4. 开发集同时包含 AI 与人工文本；
5. 最终选择同时考虑检出率和人工误检率。
